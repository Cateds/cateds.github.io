# Personal Homepage

基于 Astro + SolidJS 的个人主页，采用暖色调配色和清爽扁平风格，包含弹性粒子背景效果。

## 功能特性

- **Notes** - 按学期组织的笔记，可展开学科卡片
- **Repos** - GitHub 仓库卡片展示
- **Blog** - 时间轴布局的博客，支持标签筛选
- **Links** - 链接页面
- **粒子背景** - 弹簧振子模型 + Perlin 噪声流场
- **深色/浅色主题** - 跟随系统或手动切换
- **响应式设计** - 适配移动端

## 快速开始

```bash
# 安装依赖
bun install

# 开发模式
bun run dev

# 构建
bun run build
```

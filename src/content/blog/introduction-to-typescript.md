TypeScript adds static typing to JavaScript, helping catch errors before runtime and improving developer experience.

## Basic Types

```typescript
let name: string = "Alice";
let age: number = 25;
let hobbies: string[] = ["coding", "reading"];
```

## Interfaces

Define the shape of objects:

```typescript
interface User {
  id: number;
  name: string;
  email: string;
}
```

## Why TypeScript?

1. **Catch errors early** - Type checking at compile time
2. **Better IDE support** - Autocomplete and refactoring
3. **Self-documenting code** - Types serve as documentation
4. **Safer refactoring** - Type system catches breaking changes

TypeScript has become the standard for large-scale JavaScript applications. Start using it in your next project!
